# IQ 检索库 `/iq`

独立于现有知识库/图谱的 IQ 检索库 `ems_iq`（256 维），专做 IQ 信号相似度检索与人工打标。场景：先检索判断雷达型号（返回类型 + 概率），概率低时人工打标签再入库固化。

## `POST /iq/ingest` — 入库打标

**URL**：`POST http://192.168.31.15:8001/iq/ingest`

**请求数据**（`application/json`）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `doc_id` | UUID | 是 | 文档 uuid（须先经 `/parse-iq` 登记） |
| `category` | string | 是 | 人工类别标签（雷达型号/类型）；空串 → 422 |

流程：取回 H5 → 重跑 IQ 管道 → 256 维向量（片段 mean-pool）→ 写 `ems_iq`（标量 + 类别 + 向量）→（若 `GRAPHRAG_ENABLED=true`）`md + "\n\n类别:{category}"` 正常入知识库/知识图谱并 `mark_document_in_kb`。

**请求示例**：

```json
{"doc_id": "97303300-b568-4526-9533-21138a1e0dac", "category": "某型对空搜索雷达"}
```

**响应示例**：

```json
{"doc_id": "97303300-b568-4526-9533-21138a1e0dac", "category": "某型对空搜索雷达",
 "vector_dim": 256, "graph": {"parents": 1, "children": 2}}
```

| 字段 | 说明 |
|---|---|
| `doc_id` | 文档 uuid |
| `category` | 打标类别 |
| `vector_dim` | 向量维度（256） |
| `graph` | 图谱入库计数摘要（`GRAPHRAG_ENABLED=false` 或入库失败时为 `null`） |

错误：`404` 文档不存在/源 H5 取回失败；`422` `category` 为空。

## `POST /iq/search` — 判断类型

**URL**：`POST http://192.168.31.15:8001/iq/search`

**请求数据**（`application/json`）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `doc_id` | UUID | 是 | 文档 uuid |

流程：向量化 → `ems_iq` 最近邻（`topk=3`，排除自身）→ 最近邻 `category` 作类型、余弦相似度作概率。

**请求示例**：

```json
{"doc_id": "97303300-b568-4526-9533-21138a1e0dac"}
```

**响应示例 — 命中**：

```json
{"status": "ok", "type": "某型舰载雷达", "probability": 1.0}
```

**响应示例 — 空库 / 无邻居**：

```json
{"status": "unknown", "type": "未知", "probability": null}
```

| 字段 | 说明 |
|---|---|
| `status` | `ok` / `unknown` |
| `type` | 最近邻已打标信号的类别 |
| `probability` | 最近邻余弦相似度（0~1）；低 = 置信度低，可转人工打标签 |

错误：`404` 文档不存在/源 H5 取回失败。

## `ems_iq` 集合字段（Milvus）

| 字段 | 类型 | 说明 |
|---|---|---|
| `iq_id` | VARCHAR(PK) | 文档 uuid 字符串 |
| `category` | VARCHAR(256) | 人工类别标签 |
| `modulation` / `mod_id` | VARCHAR(64) / INT64 | 调制方式预测 |
| `snr` / `sample_rate_hz` / `symbol_rate` / `attenuation_db` | FLOAT | 信号标量 |
| 24 个特征 | FLOAT | 26 特征里的数值子集 |
| `embedding` | FLOAT_VECTOR(256) | WavesFM 256 维 CLS 特征（L2 归一化，COSINE/IVF_FLAT） |
