## 0. 总纲（开发不得偏离）

1. **需求即纲领**：每模块必须能回答"支撑需求哪一条"（§1 映射表），验收按条款对账。
2. **qingxi 检索代码不参考**：`app/graphrag/query/` 已 deprecated，全新实现不看不抄不兼容。
3. **可降级不可崩 + 禁止静默降级**：任何组件故障 → 整路剥离 + `degraded[]` 三处留痕（响应体/TRACE/前端角标）。
4. **scope 从第一行代码就是必填**（评估 R4）：所有召回函数、请求模型、图谱接口签名级强制，无默认值——骨架已落地（缺 scope 直接 422，已验证）。
5. **常量/变量分离**：算法参数以 `config/*.yaml` 为单一事实源（仓内副本与文档库 CI 校验 hash 一致）；`.env` 只做部署级覆盖，启动日志打印生效值（骨架已实现，脱敏打印）。

## 2. 模型路线（V3-D4 定案：全量 BGE-M3）

**模型层只有一次部署，不再切换**。实施上仍分两期，但分期的是"sparse 股启用"，不是"换模型"：

### 一期（当前）：BGE-M3 dense-only

| 项 | 口径 |
|---|---|
| ① 路 | 单 dense 向量 search（COSINE，τ_a=0.72，top_k=100）；sparse 股未启用是**列未就绪**，不是模型缺失 |
| 双侧模型 | 离线 qingxi `.env` 与在线 retrieval `.env` **均为 `BAAI/bge-m3`**（2026-09-28 已改），向量空间天然一致 |
| 外层 RRF | 不变（k=60，1 source 1 vote）——参与路减少不影响算法 |
| sparse 未启用 | 常态缺席不算降级（属"路未启用"而非"路故障"） |
| query 向量化 | `RETRIEVAL_EMBED_MODE=remote`（嵌入端点）/ `local`（BGEM3FlagModel 懒加载）；接口 `_embed_query_full()` 已出 dense+sparse 双通道 |
| 质量纪律 | 一期检索质量为**爬坡基线**；验收口径在二期 hybrid 上实测 |

### 二期（IF-1 扩列后）：启用 hybrid，**只改配置不改代码**

**触发条件（三条同时满足）**：① 一期链路端到端跑通且降级注入测试通过；② BGE-M3 部署稳定（E1）；③ 重建窗口排期确定。

**切换 SOP**：
1. 离线侧重建 `ems_chunks`：一次补齐 `text_sparse` / `scope` / `content_version` 三列（IF-1）；sparse 值由 qingxi 已预留的 `embed_m3_full()`（dense+lexical_weights 同源产出）写入；
2. 在线侧 `config/retrieval.yaml: milvus.sparse.enabled=true`——retrieval 侧 `_embed_query_full()` + `_milvus_hybrid_search()`（hybrid_search + RRFRanker）接口已流出，**无需改代码、无需换模型、无需二次重建**；
3. 固定 query 集人工抽查召回相关性（R2 向量一致性验收）；
4. 金标准集回归（qc_dev 调参 → qc_test 一次性验收）。

**部署形态**（BGE-M3 本地化零障碍）：MIT 协议可私有化；fp16 显存约 2~3GB 单卡可跑；FlagEmbedding 库内加载（qingxi 已有模式）或 TEI/vLLM 起端点；国内走 `hf-mirror.com` 镜像下载（qingxi 文档已有先例）。

```python
        keys = path.split(".")
        for k in keys[:-1]:
            node = node.setdefault(k, {})
        node[keys[-1]] = val
    cfg["_backend"] = s.retrieval_backend
    return cfg
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/app/store/hash_embed.py
"""确定性哈希嵌入（dev/fake 通道专用）——不依赖 GPU、不依赖模型权重。

用途与边界（重要）：
  - 仅用于【本地无模型环境】跑通全链路（seed 建库 + fake 后端检索 + 契约测试）
  - 生产/验收必须用 BGE-M3：RETRIEVAL_EMBED_MODE=local 或 embed 服务 EMBED_BACKEND=bge_m3
  - 同一份算法同时被 ① 离线 seed 建库 ② 在线 query 向量化 使用，
    保证 fake 通道下 query 与 doc 在同一向量空间（否则检索结果无意义）
  - 语义能力仅限"字面/词面重叠"，不得用它评估召回率（M-D5 消融必须换真模型）

算法：hashing trick + 符号哈希 + sublinear TF + L2 归一（与 BGE-M3 同为 1024 维 COSINE）
"""
from __future__ import annotations

import hashlib
import math
import re
from collections import Counter

DIM = 1024                       # 与 BGE-M3 dense 维度对齐
_WORD = re.compile(r"[A-Za-z0-9]+(?:[._-][A-Za-z0-9]+)*")
_CJK = re.compile(r"[\u4e00-\u9fff]")


def tokenize(text: str) -> list[str]:
    """中文按字 + 相邻二元组（保留部分词序信息），英数按词并小写。"""
    text = text or ""
    toks: list[str] = []
    for m in _WORD.finditer(text):
        toks.append("w:" + m.group(0).lower())
    # 中文：单字 + bigram
    buf: list[str] = []
    for ch in text:
        if _CJK.match(ch):
            buf.append(ch)
        else:
            if buf:
                toks.extend("c:" + c for c in buf)
                toks.extend("b:" + buf[i] + buf[i + 1] for i in range(len(buf) - 1))
                buf = []
    if buf:
        toks.extend("c:" + c for c in buf)
        toks.extend("b:" + buf[i] + buf[i + 1] for i in range(len(buf) - 1))
    return toks


def _h(token: str) -> int:
    return int.from_bytes(hashlib.blake2b(token.encode("utf-8"), digest_size=8).digest(), "big")


def hash_embedding(text: str, dim: int = DIM) -> list[float]:
    """text -> L2 归一化 dense 向量（长度 dim）。"""
    vec = [0.0] * dim
    tf = Counter(tokenize(text))
    for tok, n in tf.items():
        h = _h(tok)
        idx = h % dim
        sign = 1.0 if (h >> 63) & 1 else -1.0
        vec[idx] += sign * (1.0 + math.log(n))          # sublinear TF
    norm = math.sqrt(sum(v * v for v in vec)) or 1.0
    return [round(v / norm, 6) for v in vec]


def hash_sparse(text: str, dim: int = 30000) -> dict[int, float]:
    """text -> Milvus SPARSE_FLOAT_VECTOR 形态 {token_id: weight}（模拟 lexical_weights）。

    权重 = sublinear TF，不做 IDF（IDF 需要全量语料统计，fake 通道不需要）。
    """
    out: dict[int, float] = {}
    tf = Counter(tokenize(text))
    for tok, n in tf.items():
        out[_h(tok) % dim] = round(1.0 + math.log(n), 4)
    return out


def cosine(a: list[float], b: list[float]) -> float:
    """两向量余弦相似度（两者均已归一化时即点积）。"""
    n = min(len(a), len(b))
    s = 0.0
    for i in range(n):
        s += a[i] * b[i]
    return s


def lex_overlap(query_sparse: dict[int, float], doc_sparse: dict[int, float]) -> float:
    """稀疏打分（模拟 BM25 的内积排序效果）：Σ q_w * d_w。"""
    if not query_sparse or not doc_sparse:
        return 0.0
    small, large = (query_sparse, doc_sparse) if len(query_sparse) < len(doc_sparse) else (doc_sparse, query_sparse)
    return sum(w * large.get(k, 0.0) for k, w in small.items())
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/app/store/fake.py
"""内存三库（fake 后端）——dev/契约测试用，零外部依赖跑通全链路。

设计纪律（与项目降级思想一致，禁止"两套代码路径"）：
  - fake 与 real 共用【同一份接口签名】，route 层只认接口不认实现
  - fake 数据来自 scripts/gen_seed.py 产出的 data/seed/*.json，与真库同构
  - 故障注入：RETRIEVAL_FAULT_INJECT=vector,graph,pg,llm,rerank
    -> 对应方法抛异常，用于真跑降级矩阵（G-QC-03 要求"行为+留痕"双验）
  - 生产禁用：RETRIEVAL_BACKEND 必须为 real，启动时校验（见 config.py）
"""
from __future__ import annotations

import json
import logging
from pathlib import Path
from typing import Iterable

from .hash_embed import cosine, lex_overlap

log = logging.getLogger("retrieval.store.fake")

ROOT = Path(__file__).resolve().parent.parent.parent
DEFAULT_SEED_DIR = ROOT / "data" / "seed"


class FaultInjected(RuntimeError):
    """故障注入专用异常（测试用，生产不会出现）。"""


class FakeStore:
    """内存版 PG(parents) + Milvus(chunks/entities) + Neo4j(edges)。"""

    def __init__(self, seed_dir: Path | str = DEFAULT_SEED_DIR, faults: Iterable[str] = ()) -> None:
        d = Path(seed_dir)
        self.faults = {f.strip() for f in faults if f and f.strip()}
        self.chunks: dict[str, dict] = {}
        self.parents: dict[str, dict] = {}
        self.entities: dict[str, dict] = {}
        self.edges: list[dict] = []
        self._adj: dict[str, list[tuple[str, str, float]]] = {}
        self._binds: dict[str, list[str]] = {}      # entity_id -> [child_id]
        self._load(d)
        log.info("fake store loaded: chunks=%d parents=%d entities=%d edges=%d faults=%s",
                 len(self.chunks), len(self.parents), len(self.entities),
                 len(self.edges), sorted(self.faults) or "-")

    # ─────────────────────────── 装载 ───────────────────────────
    def _load(self, d: Path) -> None:
        self.parents = {r["parent_id"]: r for r in self._read(d / "parents.json")}
        self.chunks = {r["child_id"]: r for r in self._read(d / "chunks.json")}
        self.entities = {r["entity_id"]: r for r in self._read(d / "entities.json")}
        self.edges = self._read(d / "edges.json")
        for e in self.edges:
            if e.get("rel") == "BINDS":
                # 段落绑定边单独存放，不进实体邻接表（图谱页只画实体图）
                self._binds.setdefault(e["src"], []).append(e["dst"])
                continue
            self._adj.setdefault(e["src"], []).append((e["dst"], e.get("rel", "RELATED"), float(e.get("weight", 1.0))))
            self._adj.setdefault(e["dst"], []).append((e["src"], e.get("rel", "RELATED"), float(e.get("weight", 1.0))))

    @staticmethod
    def _read(p: Path) -> list[dict]:
        if not p.exists():
            raise FileNotFoundError(
                f"seed 数据缺失: {p} —— 请先运行 `python scripts/gen_seed.py`（fake 后端的唯一数据来源）"
            )
        with p.open("r", encoding="utf-8") as f:
            return json.load(f)

    # ─────────────────────────── Milvus 侧 ───────────────────────────
    def _check(self, key: str) -> None:
        if key in self.faults:
            raise FaultInjected(f"fault injected: {key}")

    def _scope_ok(self, row: dict, scope: list[str] | None) -> bool:
        if not scope:
            return True
        return row.get("kb_id") in set(scope)

    def search_chunks(
        self,
        dense: list[float],
        sparse: dict[int, float] | None = None,
        *,
        top_k: int = 50,
        scope: list[str] | None = None,
        tau: float = 0.0,
        hybrid: bool = False,
    ) -> list[dict]:
        """返回 [{"id","distance","entity":{...}}]，形状对齐 pymilvus MilvusClient.search。"""
        self._check("vector")
        scored: list[tuple[float, float, dict]] = []
        for c in self.chunks.values():
            if not self._scope_ok(c, scope):
                continue
            ds = cosine(dense, c.get("embedding", []))
            if hybrid and sparse:
                ls = lex_overlap(sparse, c.get("sparse") or {})
                # 内层 RRFRanker 等价：用两个排名序列的 RRF 融合（与 Milvus 语义一致）
                scored.append((ds, ls, c))
            else:
                if ds < tau:
                    continue
                scored.append((ds, 0.0, c))
        if hybrid and sparse:
            return self._rrf_rows(scored, top_k)
        scored.sort(key=lambda x: x[0], reverse=True)
        return [
            {"id": c["child_id"], "distance": s,
             "entity": {k: v for k, v in c.items() if k not in ("embedding", "sparse")}}
            for s, _, c in scored[:top_k]
        ]

    @staticmethod
    def _rrf_rows(scored: list[tuple[float, float, dict]], top_k: int, k: int = 60) -> list[dict]:
        dense_rank = {id(c): i + 1 for i, (ds, _, c) in enumerate(sorted(scored, key=lambda x: x[0], reverse=True))}
        sparse_rank = {id(c): i + 1 for i, (_, ls, c) in enumerate(sorted(scored, key=lambda x: x[1], reverse=True))}
        agg: dict[str, dict] = {}
        for ds, _, c in scored:
            r = 1.0 / (k + dense_rank[id(c)]) + 1.0 / (k + sparse_rank[id(c)])
            cur = agg.get(c["child_id"])
            if cur is None or r > cur["score"]:
                agg[c["child_id"]] = {
                    "score": r,
                    "row": {"id": c["child_id"], "distance": round(r, 6),
                            "entity": {kk: vv for kk, vv in c.items() if kk not in ("embedding", "sparse")}},
                }
        out = sorted(agg.values(), key=lambda x: x["score"], reverse=True)
        return [x["row"] for x in out[:top_k]]

    def knn_entities(self, dense: list[float], *, top_k: int = 10,
                     scope: list[str] | None = None, tau: float = 0.0) -> list[dict]:
        self._check("vector")
        rows = []
        for e in self.entities.values():
            if not self._scope_ok(e, scope):
                continue
            s = cosine(dense, e.get("embedding", []))
            if s < tau:
                continue
            rows.append((s, e))
        rows.sort(key=lambda x: x[0], reverse=True)
        return [{"id": e["entity_id"], "distance": s, "entity": e} for s, e in rows[:top_k]]

    # ─────────────────────────── Neo4j 侧 ───────────────────────────
    def expand(self, entity_ids: list[str], scope: list[str] | None = None,
               *, hops: int = 2, max_degree: int = 50, limit: int = 50) -> list[dict]:
        """1~N 跳邻域 -> BINDS 回捞子块（对齐 graph_route._expand_and_backfill 的 Cypher 语义）。"""
        self._check("graph")
        seen = set(entity_ids)
        frontier = list(entity_ids)
        for _ in range(max(1, hops)):
            nxt: list[str] = []
            for eid in frontier:
                for dst, _rel, _w in self._adj.get(eid, []):
                    if dst not in seen:
                        seen.add(dst)
                        nxt.append(dst)
            frontier = nxt
            if not frontier:
                break
        # 度数截断（高度数实体按 confidence 截断，防爆炸）
        kept = [e for e in seen if len(self._adj.get(e, [])) <= max_degree]
        out: dict[str, dict] = {}
        for eid in kept:
            for cid in self._binds.get(eid, []):
                c = self.chunks.get(cid)
                if not c or not self._scope_ok(c, scope):
                    continue
                out[cid] = {"child_id": cid, "parent_id": c.get("parent_id", ""),
                            "content": c.get("content", ""), "kb_id": c.get("kb_id", ""),
                            "kg_entity_ids": c.get("kg_entity_ids", []),
                            "via_entity": eid}
                if len(out) >= limit:
                    return list(out.values())
        return list(out.values())

    def subgraph(self, focus_entities: list[str], scope: list[str] | None = None,
                 *, hops: int = 1, node_limit: int = 50, edge_limit: int = 200,
                 relation_types: list[str] | None = None) -> tuple[list[dict], list[dict], bool]:
        """返回 (nodes, edges, pruned)。节点带 hops_from_focus，边带 evidence（G-API-02）。"""
        self._check("graph")
        hop_of = {e: 0 for e in focus_entities}
        frontier = list(focus_entities)
        for d in range(1, max(1, hops) + 1):
            nxt = []
            for eid in frontier:
                for dst, _rel, _w in self._adj.get(eid, []):
                    if dst not in hop_of:
                        hop_of[dst] = d
                        nxt.append(dst)
            frontier = nxt
            if not frontier:
                break
        pruned = len(hop_of) > node_limit
        keep_eids = list(hop_of)[:node_limit]

        nodes = []
        for eid in keep_eids:
            e = self.entities.get(eid, {"entity_id": eid, "name": eid, "type": "Unknown", "kb_id": ""})
            if not self._scope_ok(e, scope):
                continue
            ev = None
            for cid in self._binds.get(eid, [])[:1]:
                c = self.chunks.get(cid)
                if c:
                    ev = {"child_id": cid, "span": c.get("span"), "parent_id": c.get("parent_id")}
            nodes.append({"id": eid, "name": e.get("name", eid),
                          "type": e.get("type", "Unknown"),
                          "kb_id": e.get("kb_id", ""),
                          "degree": len(self._adj.get(eid, [])),
                          "hops_from_focus": hop_of[eid],
                          "is_focus": eid in focus_entities,
                          "evidence": ev})
        keep = {n["id"] for n in nodes}
        edges = []
        for e in self.edges:
            if e["src"] in keep and e["dst"] in keep:
                if relation_types and e.get("rel") not in relation_types:
                    continue
                ev = e.get("evidence")
                if not ev:   # 兜底：无证据的边不得渲染为可点击
                    cid = e.get("dst") if e.get("rel") == "BINDS" else None
                    c = self.chunks.get(cid) if cid else None
                    ev = ({"child_id": cid, "span": c.get("span"), "parent_id": c.get("parent_id")}
                          if c else {"child_id": "", "span": [0, 0], "parent_id": None})
                edges.append({"source": e["src"], "target": e["dst"],
                              "rel": e.get("rel", "RELATED"),
                              "confidence": min(1.0, float(e.get("weight", 1.0))),
                              "evidence": ev})
            if len(edges) >= edge_limit:
                pruned = True
                break
        return nodes, edges, pruned

    # ─────────────────────────── PG 侧 ───────────────────────────
    def parents_batch(self, parent_ids: list[str]) -> dict[str, dict]:
        self._check("pg")
        return {
            pid: {"parent_id": pid,
                  "content": p.get("content", ""),
                  "content_version": p.get("content_version", 1),
                  "summary": p.get("summary", ""),
                  "keywords": p.get("keywords", [])}
            for pid, p in ((pid, self.parents.get(pid)) for pid in parent_ids) if p
        }

    """非 FakeStore 组件（rerank / generate / bm25）的故障注入检查。
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/app/api/retrieval.py
"""POST /api/retrieval —— SSE 主端点（M-C1）。

SSE 只是传输方式，契约对象 = 所有事件聚合后的一份响应（见 retrieval_response.v1.schema.json）：
  {contract_version, trace_id, meta, results, assets, artifacts, graph_ref, degraded, timings}
事件序列：meta -> progress* -> results -> assets -> token* -> done / error

主链：QRY-02(L1+L3) -> ①③并行召回 -> 外层 RRF -> rerank -> QRY-06 父块回捞 -> 生成 -> done
预算看门狗（QRY-07）在此真正驱动砍路：
  >3.5s 砍重排 / >4.5s 砍图路 / >5.0s 砍稀疏与 NL2Query；每砍必留 degraded（禁静默降级）
"""
from __future__ import annotations

import asyncio
import json
import logging
import time

from fastapi import APIRouter
from fastapi.responses import StreamingResponse
from pydantic import BaseModel, Field

from ..config import effective_cfg, get_settings
from ..degrade.codes import DegradedCode
from ..degrade.orchestrator import BudgetWatchdog, DegradedCollector
from ..fuse.parent_backfill import backfill, check_version
from ..fuse.rerank import rerank

from ..generate.report import stream_report
from ..graph.expand import focus_entities
from ..recall import bm25_route, graph_route, vector_route
from ..trace.spans import TraceRecorder, bind_trace, new_trace_id
from ..understand.query_parser import parse

log = logging.getLogger("retrieval.api")
router = APIRouter()
CONTRACT_VERSION = "1.0"


class RetrievalRequest(BaseModel):
    query: str = Field(min_length=1)
    scope: list[str] = Field(min_length=1)   # R4：必填无默认值（权限从第一行代码就是硬约束）
    session_id: str | None = None            # QRY-00 会话（本期单轮直通）
    eval_mode: bool = False                  # EV-1/EV-5：评测模式（不写缓存/不计被引）


def _sse(event: str, data: dict) -> str:
    return f"event: {event}\ndata: {json.dumps(data, ensure_ascii=False)}\n\n"


@router.post("/api/retrieval")
async def retrieval(req: RetrievalRequest) -> StreamingResponse:
    async def event_stream():
        trace_id = new_trace_id()
        collector = DegradedCollector()
        tracer = TraceRecorder(trace_id, eval_mode=req.eval_mode)
        watchdog = BudgetWatchdog()
        t_start = time.monotonic()
        timings: dict[str, int] = {}
        first_token_at: float | None = None

        yield _sse("meta", {"contract_version": CONTRACT_VERSION, "trace_id": trace_id,
                            "eval_mode": req.eval_mode})
        try:
            # ── QRY-02 查询理解（L1 词典正则 + L3 校验器）──
            span = tracer.start("understand")
            pq = parse(req.query, collector)
            span.hit_count = len(pq.conditions)
            span.degraded_codes = collector.codes()
            span.close()
            timings["parse_ms"] = int(span.duration_ms)
            yield _sse("progress", {"stage": "understand", "intent": pq.intent,
                                    "conditions": [c.to_dict() for c in pq.conditions]})

            # ── QRY-07 预算决策（砍路，不是砍语义）──
            cfg = effective_cfg()
            level = watchdog.current_level()
            run_graph = get_settings().retrieval_graph_route_enabled
            if level.value in ("L2", "L1", "L0"):        # >4.5s：砍图路保主链
                if run_graph:
                    collector.record(DegradedCode.BUDGET_CUT_ROUTE3,
                                     f"budget level={level.value}, elapsed={watchdog.elapsed_s():.2f}s",
                                     "graph")
                run_graph = False

            # ── 三路并行召回（② 默认关；③-B deferred）──
            span = tracer.start("recall")
            t0 = time.monotonic()
            vec_hits, bm25_hits, graph_hits = await asyncio.gather(
                vector_route.recall(req.query, scope=req.scope, collector=collector),
                bm25_route.recall(req.query, scope=req.scope, collector=collector),
                graph_route.recall(req.query, scope=req.scope, collector=collector)
                if run_graph else asyncio.sleep(0, result=[]),
            )
            timings["vector_ms"] = int((time.monotonic() - t0) * 1000)
            span.hit_count = len(vec_hits) + len(bm25_hits) + len(graph_hits)
            span.degraded_codes = collector.codes()
            span.close()
            yield _sse("progress", {"stage": "recall",
                                    "vector": len(vec_hits), "bm25": len(bm25_hits),
                                    "graph": len(graph_hits),
                                    "budget_level": level.value})

            # ── 外层 RRF（1 source 1 vote）──
            span = tracer.start("fuse")
            fused = rrf_fuse({"vector_hybrid": vec_hits, "bm25": bm25_hits,
                              "graph_local": graph_hits},
                             k=int(cfg.get("fusion", {}).get("k", 60)),
                             top_k=int(cfg.get("fusion", {}).get("top_k", 50)))
            span.hit_count = len(fused)
            span.close()

            # ── Rerank（预算 L3 砍精排；超时/失败直出 RRF 序）──
            span = tracer.start("rerank")
            t0 = time.monotonic()
            level = watchdog.current_level()
            if level.value in ("L3", "L2", "L1", "L0"):   # >3.5s：砍重排
                collector.record(DegradedCode.RERANK_SKIPPED,
                                 f"budget level={level.value}", "rerank")
                top = fused[:int(cfg.get("reranker", {}).get("top_k_out", 5))]
            else:
                top = await rerank(req.query, fused, collector)
            timings["rerank_ms"] = int((time.monotonic() - t0) * 1000)
            span.hit_count = len(top)
            span.hit_parent_ids = [h.parent_id for h in top]
            span.degraded_codes = collector.codes()
            span.close()

            # ── QRY-06 父块回捞（PG 熔断 -> 行内 content 兜底）──
            span = tracer.start("backfill")
            t0 = time.monotonic()
            parents = await backfill(top, collector)
            timings["pg_fetch_ms"] = int((time.monotonic() - t0) * 1000)
            span.hit_count = len(parents)
            span.close()

            # ── results（证据锚点 child_id + span；IF-2 未就位则 span=null 并留痕）──
            results = []
            for i, h in enumerate(top, start=1):
                p = parents.get(h.parent_id, {})
                if p and not check_version(h, p):
                    collector.record(DegradedCode.PARENT_FETCH_FAILED,
                                     f"content_version drift: {h.child_id}", "pg_fetch")
                sp = h.meta.get("span")
                if not sp and not collector.has(DegradedCode.EVIDENCE_SPAN_MISSING):
                    collector.record(DegradedCode.EVIDENCE_SPAN_MISSING,
                                     "IF-2 未就位：子块无 span，前端不得渲染回原文高亮", "vector")
                results.append({
                    "parent_id": h.parent_id,
                    "child_id": h.child_id,
                    "title": h.meta.get("section") or None,
                    "content": p.get("content") or h.content,
                    "metadata": {"kb_id": h.meta.get("kb_id", ""),
                                 "voted_by": h.meta.get("voted_by", []),
                                 "rank": i,
                                 "via_entity": h.meta.get("via_entity")},
                    "evidence": {"child_id": h.child_id, "span": sp},
                    "score": {"rrf": h.meta.get("rrf_score"),
                              "rerank": h.meta.get("rerank_score")},
                })
            yield _sse("results", {"hits": results, "degraded": collector.as_list()})

            # ── assets / artifacts（IF-5 未就位：空表，不算降级）──
            yield _sse("assets", {"items": []})

            # ── graph_ref：focus 取自重排 Top-N 命中实体（不取 query 里的实体）──
            focus = focus_entities(top, top_n=int(cfg.get("graph_ref", {}).get("top_n", 5)))
            bind_trace(trace_id, focus, req.scope, [h.child_id for h in top])
            sg = cfg.get("subgraph", {})
            graph_ref = {
                "available": bool(focus),
                "focus_entities": focus,
                "endpoint": "/api/graph/subgraph",
                "binding": "trace_id",
                "default_hops": int(sg.get("default_hops", 1)),
                "node_limit": int(sg.get("node_limit", 50)),
                "edge_limit": int(sg.get("edge_limit", 200)),
            }

            # ── RPT 流式生成（LLM 熔断 -> 无 token，done 带降级）──
            span = tracer.start("generate")
            async for tok in stream_report(req.query, top, parents, collector):
                if tok:
                    if first_token_at is None:
                        first_token_at = time.monotonic()
                        timings["first_token_ms"] = int((first_token_at - t_start) * 1000)
                    yield _sse("token", {"text": tok})
            span.degraded_codes = collector.codes()
            span.close()

            timings["total_ms"] = int((time.monotonic() - t_start) * 1000)
            yield _sse("done", {
                "contract_version": CONTRACT_VERSION,
                "trace_id": trace_id,
                "meta": {"intent": pq.intent, "query_rewritten": None,
                         "conditions": [c.to_dict() for c in pq.conditions]},
                "graph_ref": graph_ref,
                "degraded": collector.as_list(),
                "timings": timings,
                "budget_level": watchdog.current_level().value,
            })
        except Exception as e:  # 兜底：主链任何未捕获异常 -> error 事件，绝不裸 500
            log.exception("retrieval pipeline failed: %s", e)
            yield _sse("error", {"trace_id": trace_id, "message": str(e)[:300],
                                 "degraded": collector.as_list()})
        finally:
            tracer.export_async()

    return StreamingResponse(event_stream(), media_type="text/event-stream")
```

```python
            "layout_hint": "concentric",
            "scope_filtered": bool(focus) and len(nodes_raw) < len(focus),

def _neo4j_subgraph(focus: list[str], scope: list[str], hops: int,
                    node_limit: int, edge_limit: int,
                    relation_types: list[str] | None) -> tuple[list[dict], list[dict]]:
    from neo4j import GraphDatabase  # 懒加载

    s = get_settings()
    cy_nodes = """
    MATCH (f:Entity)-[*0..$hops]-(n:Entity)
    WHERE f.entity_id IN $focus AND n.kb_id IN $scope
    WITH DISTINCT n, [ (n)-[]-() | 1 ] AS degs
    RETURN n.entity_id AS id, n.name AS name, n.type AS type, n.kb_id AS kb_id,
           size(degs) AS degree, n.entity_id IN $focus AS is_focus
    LIMIT $node_limit
    """
    cy_edges = """
    MATCH (a:Entity)-[r]->(b:Entity)
    WHERE a.entity_id IN $ids AND b.entity_id IN $ids
      AND ($rel_types IS NULL OR type(r) IN $rel_types)
    RETURN a.entity_id AS source, b.entity_id AS target, type(r) AS rel,
           r.confidence AS confidence,
           r.evidence_child_id AS child_id, r.span_start AS span_start,
           r.span_end AS span_end, r.parent_id AS parent_id
    LIMIT $edge_limit
    """
    driver = GraphDatabase.driver(s.neo4j_uri, auth=(s.neo4j_user, s.neo4j_password))
    try:
        with driver.session() as sess:
            nodes = [dict(r) for r in sess.run(cy_nodes, focus=focus, scope=scope,
                                               hops=hops, node_limit=node_limit)]
            ids = [n["id"] for n in nodes]
            edges = []
            for r in sess.run(cy_edges, ids=ids, rel_types=relation_types, edge_limit=edge_limit):
                d = dict(r)
                edges.append({
                    "source": d["source"], "target": d["target"], "rel": d["rel"],
                    "confidence": d.get("confidence"),
                    "evidence": {"child_id": d.get("child_id") or "",
                                 "span": [d.get("span_start") or 0, d.get("span_end") or 0],
                                 "parent_id": d.get("parent_id")},
                })
            return nodes, edges
    finally:
        driver.close()
```

```python
from ..degrade.orchestrator import DegradedCollector

# L2 output_schema 的 intent 枚举（yaml 里 STRUCTURED_ONLY 与 V2.0 的 PURE_STRUCTURED 同义，统一用后者）
INTENTS = {"ENTITY_LEVEL", "GLOBAL", "HYBRID", "PURE_STRUCTURED"}

# 字段 -> 归一基准单位（契约 conditions[].unit；与 query_parser.yaml unit_convert.base 一致）
UNIT_BASE = {"rf": "GHz", "pw": "us", "prf": "Hz", "doa": "deg", "snr": "dB"}

# L3 量纲合理区间（query_parser.yaml validator V-03，归一单位后）
RANGE_LIMITS = {
    "rf": (0.01, 300.0),        # GHz
    "pw": (0.01, 10000.0),      # us
    "prf": (1.0, 2_000_000.0),  # Hz
    "doa": (0.0, 360.0),        # deg
    "snr": (-40.0, 80.0),       # dB
}


# 内部 op -> 契约 op（api/retrieval_response.v1.schema.json 的枚举）
# point 用 eq（容差由 structured_filter.yaml tolerance 决定，不进本契约）
OP_TO_CONTRACT = {"point": "eq", "range": "between", "eq": "eq", "month": "between", "day": "between"}


@dataclass
class Condition:
    field: str
    op: str                    # range / point / eq（内部口径）
    value: object
    confidence: float
    raw: str = ""
    strength: str = "soft"     # 过渡期恒 soft（④ 路预留），不进契约（契约无此字段）

    def to_dict(self) -> dict:
        """契约形状：field/op/value/unit/raw/confidence（additionalProperties=false，禁加字段）。"""
        return {
            "field": self.field,
            "op": OP_TO_CONTRACT.get(self.op, "eq"),
            "value": self.value,
            "unit": UNIT_BASE.get(self.field),
            "raw": self.raw or None,
            "confidence": round(float(self.confidence), 3),
        }


@dataclass
class ParsedQuery:
    intent: str = "ENTITY_LEVEL"
    conditions: list[Condition] = field(default_factory=list)
    rewritten: str = ""        # QRY-00 会话改写后的 query（本期单轮直通）
    l1_hit: bool = False


_UNIT_TO_BASE = {  # 从 query_parser.yaml unit_convert 摘出的最小实现（字段: {单位串: 倍率}）
    "rf": {"GHz": 1.0, "G": 1.0, "吉赫": 1.0, "MHz": 0.001, "M": 0.001, "兆赫": 0.001},
    "pw": {"us": 1.0, "μs": 1.0, "微秒": 1.0, "ms": 1000.0, "毫秒": 1000.0, "ns": 0.001, "纳秒": 0.001},
    "prf": {"Hz": 1.0, "赫兹": 1.0, "kHz": 1000.0, "K": 1000.0, "MHz": 1000000.0, "pps": 1.0},
    "doa": {"度": 1.0, "deg": 1.0, "°": 1.0},
}


def _l1_extract(query: str, collector: DegradedCollector) -> list[Condition]:
    """L1 正则快速通道：消费 config/query_parser.yaml 的 l1_rules。"""
    cfg = query_parser_cfg().get("l1_rules", {})
    if not cfg.get("enabled", False):
        return []
    out: list[tuple[tuple[int, int], Condition]] = []
    for rule in cfg.get("patterns", []):
        m = re.search(rule["regex"], query)
        if not m:
            continue
        o = rule["out"]
        fld, kind = o["field"], o["kind"]
        unit_tbl = _UNIT_TO_BASE.get(fld, {})
        try:
            if kind == "range":
                lo, hi = float(m.group(1)), float(m.group(2))
                unit = m.group(3) if m.lastindex and m.lastindex >= 3 else ""
                factor = unit_tbl.get(unit, 1.0)
                value = [lo * factor, hi * factor]
                op = "range"
            elif kind == "point":
                v = float(m.group(1))
                unit = m.group(2) if m.lastindex and m.lastindex >= 2 else ""
                if not unit:
                    collector.record(DegradedCode.UNIT_INFERRED, f"field={fld} bare number", "understand")
                value = v * unit_tbl.get(unit, 1.0)
                op = "point"
            else:
                continue  # toa 等时间类本期骨架暂不展开，交给 L2
            out.append((m.span(), Condition(field=fld, op=op, value=value,
                                            confidence=rule.get("confidence", 0.85),
                                            raw=m.group(0)[:32])))
        except (ValueError, IndexError):
            continue
    # 重叠吸收：span 被另一条完全包含的条件丢弃（如 range "8~12GHz" 吸收 point "12GHz"）
    kept = [
        (span, c) for span, c in out
        if not any(
            os_ != span and os_[0] <= span[0] and span[1] <= os_[1]
            for os_, _ in out
        )
    ]
    kept.sort(key=lambda x: x[0][0])
    return [c for _, c in kept]


def _l3_validate(conds: list[Condition], collector: DegradedCollector) -> list[Condition]:
    """L3 校验器：字段白名单 + 量纲区间 + 区间自洽。不过则丢弃（过渡期一律 soft，无 hard）。"""
    cfg = query_parser_cfg()
    allowed = set(
        (cfg.get("l2_llm", {}).get("output_schema", {})
         .get("properties", {}).get("conditions", {})
         .get("items", {}).get("properties", {}).get("field", {})
         .get("enum", []))
    ) or set(RANGE_LIMITS)
    ok: list[Condition] = []
    for c in conds:
        if c.field not in allowed:
            collector.record(DegradedCode.CONDITION_INVALID, f"V-01 field={c.field}", "understand")
            continue
        lo, hi = RANGE_LIMITS.get(c.field, (None, None))
        vals = c.value if isinstance(c.value, list) else [c.value]
        if lo is not None and any(not (isinstance(v, (int, float)) and lo <= v < hi) for v in vals):
            collector.record(DegradedCode.CONDITION_INVALID, f"V-03 {c.field}={c.value}", "understand")
            continue
        if isinstance(c.value, list) and len(c.value) == 2 and c.value[0] > c.value[1]:
            collector.record(DegradedCode.CONDITION_INVALID, f"V-04 {c.field}={c.value}", "understand")
            continue
        ok.append(c)
    return ok


def parse(query: str, collector: DegradedCollector) -> ParsedQuery:
    """三层解析主入口（骨架版：L1+L3 真实，L2 骨架）。"""
    pq = ParsedQuery(rewritten=query)

    # L1
    conds = _l1_extract(query, collector)
    pq.l1_hit = bool(conds)

    # L2（骨架）：L1 未命中且有 LLM 端点时才调；本期未部署 -> 记降级继续
    if not pq.l1_hit:
        # TODO(M-Q2): 接 vLLM function calling（复用 qingxi llm.py 的调用模式，非检索逻辑）
        collector.record(DegradedCode.NL2QUERY_LLM_TIMEOUT, "L2 not deployed (skeleton)", "understand")

    # L3
    pq.conditions = _l3_validate(conds, collector)

    # 意图初判（骨架启发式；正式版由 L2 输出）
    if pq.conditions and len(query) <= 40:
        pq.intent = "PURE_STRUCTURED"
    else:
        pq.intent = "ENTITY_LEVEL"
    return pq
```

```python
"""① 路向量召回（M-Q1）——BGE-M3 全量定案版（2026-09-28 V3-D4）。

async def _embed_query_full(query: str) -> dict:

async def recall(query: str, *, scope: list[str], collector: DegradedCollector) -> list[Hit]:
    """① 路召回。scope 必填（无默认值，调用方不传直接 TypeError）。

    hybrid 开关：config/retrieval.yaml milvus.sparse.enabled=true 且 query 出了

def _fake_search(emb: dict, scope: list[str], cfg: dict, hybrid: bool) -> list[Hit]:

def _milvus_search(emb: dict, scope: list[str], cfg: dict) -> list[Hit]:
    """dense-only 检索（当前常态）。"""
    if cfg.get("_backend") == "fake":
        return _fake_search(emb, scope, cfg, hybrid=False)
    from pymilvus import MilvusClient  # 懒加载

    s = get_settings()
    dense_cfg = cfg["milvus"]["dense"]["primary"]
    client = MilvusClient(uri=s.milvus_uri)
    scope_expr = "kb_id in [" + ",".join(f'"{x}"' for x in scope) + "]"

def _milvus_hybrid_search(emb: dict, scope: list[str], cfg: dict) -> list[Hit]:
    """dense + sparse 库内 RRFRanker 混合检索（IF-1 扩列后启用）。

    real：pymilvus hybrid_search(AnnSearchRequest x2, RRFRanker(k=60))
    fake：FakeStore 内部按双排名序列做等价 RRF（语义对齐，非近似替代）
    列未就绪而开关被误开：回退 dense-only + 记日志（禁静默假装 hybrid）。
    """
    if cfg.get("_backend") == "fake":
        return _fake_search(emb, scope, cfg, hybrid=True)
    from pymilvus import AnnSearchRequest, MilvusClient, RRFRanker  # 懒加载

    s = get_settings()
    dense_cfg = cfg["milvus"]["dense"]["primary"]
    sparse_cfg = cfg["milvus"]["sparse"]
    client = MilvusClient(uri=s.milvus_uri)
    fields = client.describe_collection(
        collection_name=s.milvus_chunk_collection).get("fields", [])
    if sparse_cfg.get("field", "text_sparse") not in {f["name"] for f in fields}:
        log.warning("hybrid enabled but text_sparse missing; fallback dense-only")
        return _milvus_search(emb, scope, cfg)

    scope_expr = "kb_id in [" + ",".join(f'"{x}"' for x in scope) + "]"
    reqs = [
        AnnSearchRequest(
            data=[emb["dense"]],
            anns_field=dense_cfg.get("vector_field", "embedding"),
            param={"metric_type": dense_cfg.get("metric_type", "COSINE")},
            limit=int(dense_cfg.get("top_k", 100)),
            expr=scope_expr,
        ),
        AnnSearchRequest(
            data=[emb["sparse"]],
            anns_field=sparse_cfg.get("field", "text_sparse"),
            param={"metric_type": sparse_cfg.get("metric_type", "BM25")},
            limit=int(sparse_cfg.get("top_k", 100)),
            expr=scope_expr,
        ),
    ]
    res = client.hybrid_search(
        collection_name=s.milvus_chunk_collection,
        reqs=reqs,
        ranker=RRFRanker(k=int(cfg.get("hybrid", {}).get("rrfranker", {}).get("k", 60))),
        limit=int(cfg.get("hybrid", {}).get("top_k_after_hybrid", 50)),
        output_fields=["parent_id", "content", "kg_entity_ids", "kb_id", "span"],
    )
    return _to_hits(res[0], tau=0.0)   # hybrid 排序已是 RRF 序，不再叠加 τ 过滤


def _to_hits(rows, tau: float) -> list[Hit]:
    hits: list[Hit] = []
    for row in rows:
        if row["distance"] < tau:
            continue
        ent = row.get("entity", {})
        hits.append(Hit(
            child_id=str(row["id"]),
            parent_id=str(ent.get("parent_id", "")),
            rank_score=float(row["distance"]),
            source="vector_hybrid",
            content=ent.get("content", "") or "",
            kg_entity_ids=ent.get("kg_entity_ids") or [],
            meta={"kb_id": ent.get("kb_id", ""),
                  "span": ent.get("span"),           # IF-2：离线给了就有，没给就是 None
                  "section": ent.get("section", "")},
        ))
    return hits
```

```python
"""③-A Local 图遍历（M-R1）。

def _expand_and_backfill(entity_ids: list[str], scope: list[str], gcfg: dict) -> list[Hit]:
    """图遍历 + BINDS 回捞。"""
    cfg = effective_cfg()
    if cfg.get("_backend") == "fake":
        from ..store.fake import get_fake_store
        rows = get_fake_store().expand(
            entity_ids, scope,
            hops=int(gcfg.get("hops", 2)),
            max_degree=int(gcfg.get("max_degree", 50)),
            limit=int(gcfg.get("limit", 50)),
        )
        return [
            Hit(child_id=str(r["child_id"]), parent_id=str(r.get("parent_id", "")),
                rank_score=1.0, source="graph_local", content=r.get("content", ""),
                kg_entity_ids=r.get("kg_entity_ids", []),
                meta={"kb_id": r.get("kb_id", ""), "via_entity": r.get("via_entity", "")})
            for r in rows
        ]

    from neo4j import GraphDatabase  # 懒加载
    s = get_settings()
    cypher = """
    MATCH (e:Entity)-[r*1..$hops]-(n:Entity)<-[:BINDS]-(seg:Segment)
    WHERE e.entity_id IN $eids AND seg.kb_id IN $scope
    WITH seg, size([(n)-[]-() | 1]) AS deg
    WHERE deg <= $max_deg
    RETURN DISTINCT seg.chunk_id AS child_id, seg.parent_id AS parent_id,
           seg.content AS content, seg.kb_id AS kb_id, seg.span AS span
    LIMIT $limit
    """
    driver = GraphDatabase.driver(s.neo4j_uri, auth=(s.neo4j_user, s.neo4j_password))
    try:
        with driver.session() as sess:
            rows = sess.run(cypher, eids=entity_ids, scope=scope,
                            hops=int(gcfg.get("hops", 2)),
                            max_deg=int(gcfg.get("max_degree", 50)),
                            limit=int(gcfg.get("limit", 50)))
            return [
                Hit(child_id=str(r["child_id"]), parent_id=str(r["parent_id"] or ""),
                    rank_score=1.0, source="graph_local", content=r["content"] or "",
                    meta={"kb_id": r["kb_id"] or "", "span": r["span"]})
                for r in rows

    finally:
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/app/fuse/rrf.py
"""外层 RRF 融合（M-Q4）——纯算法，绿档模块，完整实现。

纪律：
  - 1 source 1 vote（G-QC-02）：同一来源多路命中先组内合并，跨来源才进 RRF
  - RRF score = Σ 1 / (k + rank)，rank 从 1 起
  - 单路被剥离不影响其他路相对序（这是选 RRF 而非加权求和的原因）
"""
from __future__ import annotations

from dataclasses import dataclass, field


@dataclass
class Hit:
    """一路召回的单个命中。source 取值：vector_hybrid / bm25 / graph_local / graph_global。"""

    child_id: str
    parent_id: str = ""
    rank_score: float = 0.0      # 该来源内部原始分（仅展示用，不参与融合）
    source: str = ""
    content: str = ""            # Milvus 行内冗余（PG 熔断兜底用）
    kg_entity_ids: list[str] = field(default_factory=list)
    meta: dict = field(default_factory=dict)


def merge_within_source(hits: list[Hit]) -> list[Hit]:
    """同一来源内部按 child_id 去重：保留该来源内最高 rank（rank_score 最大）。"""
    best: dict[str, Hit] = {}
    for h in hits:
        cur = best.get(h.child_id)
        if cur is None or h.rank_score > cur.rank_score:
            best[h.child_id] = h
    return sorted(best.values(), key=lambda h: h.rank_score, reverse=True)


def rrf_fuse(
    sources: dict[str, list[Hit]],
    k: int = 60,
    top_k: int = 50,
) -> list[Hit]:
    """跨来源 RRF 融合。

    sources: {source_name: [Hit, ...]（按该来源优劣排序）}
    返回：融合后 Hit 列表，meta 里带 rrf_score 与 voted_by（命中来源清单）。
    """
    k = int(k)
    agg: dict[str, dict] = {}
    for src_name, hits in sources.items():
        if not hits:
            continue  # 被剥离的路传空表/缺席即可，天然不投票
        merged = merge_within_source(hits)
        for rank, h in enumerate(merged, start=1):
            slot = agg.setdefault(
                h.child_id,
                {"hit": h, "score": 0.0, "voted_by": []},
            )
            slot["score"] += 1.0 / (k + rank)  # 1 source 1 vote
            slot["voted_by"].append(src_name)
    out: list[Hit] = []
    for slot in agg.values():
        h = slot["hit"]
        h.meta["rrf_score"] = slot["score"]
        h.meta["voted_by"] = slot["voted_by"]
        out.append(h)
    out.sort(key=lambda h: h.meta["rrf_score"], reverse=True)
    return out[:top_k]


def assert_one_source_one_vote(sources: dict[str, list[Hit]]) -> None:
    """G-QC-02 断言辅助：每来源内部不得有重复 child_id（融合前调用）。"""
    for name, hits in sources.items():
        ids = [h.child_id for h in hits]
        dup = {i for i in ids if ids.count(i) > 1}
        assert not dup, f"source {name} has duplicated child_id before merge: {dup}"
```

```python
def _local_scores(query: str, texts: list[str]) -> list[float]:
```

```python
def build_prompt(query: str, hits: list[Hit], parents: dict[str, dict]) -> list[dict]:
    """组装 messages：父块全文进 context，子块给编号 [n]。"""
    lines = []
    for i, h in enumerate(hits, start=1):
        p = parents.get(h.parent_id, {})

    user = (

        "4) 置信度与依据不足说明。结论必须由证据支撑。"
    )
    return [{"role": "system", "content": SYSTEM}, {"role": "user", "content": user}]


async def stream_report(
    query: str,
    hits: list[Hit],
    parents: dict[str, dict],
    collector: DegradedCollector,

                         "LLM endpoint not configured", "generate")
        return

    url = s.graphrag_llm_base_url.rstrip("/") + "/chat/completions"
    try:
        from ..store.fake import guard
        guard("llm")          # 故障注入（跑降级矩阵用）
        import httpx
        async with httpx.AsyncClient(timeout=60.0) as cli:

                "POST", url,
                headers={"Authorization": f"Bearer {s.graphrag_llm_api_key}"},
                json={"model": s.graphrag_llm_model, "messages": messages,
                      "stream": True, "temperature": 0.2},

                r.raise_for_status()
                async for line in r.aiter_lines():
                    if not line or not line.startswith("data:"):
                        continue
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/app/degrade/orchestrator.py
"""QRY-07 降级编排器（M-D1）骨架。

职责：
  1. 预算看门狗：按 config/retrieval.yaml degradation.cutoffs 把累计耗时映射到 L0~L4
  2. 留痕收集器：全链 degraded[] 统一收口（响应体 / TRACE / 前端角标三处同源）

红线：禁止静默降级——任何降级动作必须过 DegradedCollector.record()。
"""
from __future__ import annotations

import time
from dataclasses import dataclass, field

from ..config import effective_cfg
from .codes import BudgetLevel, DegradedCode, step_of


@dataclass
class DegradedCollector:
    """一次请求的降级留痕收集器。trace span 与响应体 degraded[] 都从这里取。

    输出形状严格对齐 api/retrieval_response.v1.schema.json：
        {"step": <枚举>, "code": str, "message": str|None, "at": ISO8601}
    内部保留 raw（stage/detail）供排障与 TRACE，但对外只吐契约形状。
    """

    items: list[dict] = field(default_factory=list)

    def record(self, code: DegradedCode, detail: str = "", stage: str = "") -> None:
        code_v = code.value if isinstance(code, DegradedCode) else str(code)
        self.items.append({
            "code": code_v,
            "stage": stage or step_of(code_v),
            "detail": detail,
            "at": time.strftime("%Y-%m-%dT%H:%M:%S"),
        })

    def has(self, code: DegradedCode) -> bool:
        return any(i["code"] == code.value for i in self.items)

    def raw(self) -> list[dict]:
        return list(self.items)

    def as_list(self) -> list[dict]:
        """契约形状（响应体 / 前端角标 / TRACE 三处同源）。

        step 必须由 code 经 STEP_MAP 推导，不接受调用方随手传的字符串——
        否则会出现 'backfill' 之类不在枚举里的值，契约校验直接失败。
        """
        return [{"step": step_of(i["code"]), "code": i["code"],
                 "message": i["detail"] or None, "at": i["at"]} for i in self.items]

    def codes(self) -> list[str]:
        return [i["code"] for i in self.items]


class BudgetWatchdog:
    """预算看门狗：start() 后随时 current_level()，驱动砍路决策。"""

    def __init__(self, budget_ms: int | None = None) -> None:
        cfg = effective_cfg().get("degradation", {})
        self._budget_s = (budget_ms or int(cfg.get("budget_s", 5.2) * 1000)) / 1000.0
        # cutoffs 按 threshold_s 升序
        self._cutoffs = sorted(
            cfg.get("cutoffs", []), key=lambda c: c.get("threshold_s", 0)
        )
        self._t0 = time.monotonic()

    def elapsed_s(self) -> float:
        return time.monotonic() - self._t0

    def current_level(self) -> BudgetLevel:
        """返回已超阈值中最严格的一档（elapsed 越大砍得越狠）。"""
        e = self.elapsed_s()
        level = BudgetLevel.L4
        for c in self._cutoffs:  # 升序遍历，最后一个被超过的 threshold 生效
            if e > c.get("threshold_s", 0):
                level = BudgetLevel(c.get("level", "L4"))
        return level

    def over_budget(self) -> bool:
        return self.elapsed_s() > self._budget_s
```

```python
# trace_id 绑定（M-R4/R5）：检索请求 -> focus 实体 + scope

# 生产应换 Redis（TTL 30min）；此处为进程内存实现，接口不变（IF-7 Redis 本期推迟）
# ────────────────────────────────────────────────────────────
TRACE_TTL_S = 1800
_binding: dict[str, dict] = {}


def bind_trace(trace_id: str, focus_entities: list[str], scope: list[str],
               child_ids: list[str] | None = None) -> None:
    _purge()
    _binding[trace_id] = {"ts": time.time(), "focus_entities": list(focus_entities),
                          "scope": list(scope), "child_ids": list(child_ids or [])}


def get_binding(trace_id: str) -> dict | None:
    _purge()
    b = _binding.get(trace_id)
    return b if b else None


def _purge() -> None:
    now = time.time()
    for k in [k for k, v in _binding.items() if now - v["ts"] > TRACE_TTL_S]:
        _binding.pop(k, None)


@dataclass
class Span:
    stage: str                      # understand/recall_vector/recall_graph/fuse/rerank/backfill/generate
    status: str = "ok"              # ok / degraded / failed
    t0: float = field(default_factory=time.monotonic)
    duration_ms: float = 0.0
    hit_count: int = 0
    hit_parent_ids: list[str] = field(default_factory=list)
    degraded_codes: list[str] = field(default_factory=list)
    detail: str = ""

    def close(self) -> None:
        self.duration_ms = round((time.monotonic() - self.t0) * 1000, 1)

    def to_dict(self) -> dict:
        return {
            "stage": self.stage,
            "status": self.status,
            "duration_ms": self.duration_ms,
            "hit_count": self.hit_count,
            "hit_parent_ids": self.hit_parent_ids,
            "degraded_codes": self.degraded_codes,
            "detail": self.detail,
        }


class TraceRecorder:
    """单请求 span 收集 + 异步导出。eval_mode=true 时单独打标（EV-5）。"""

    def __init__(self, trace_id: str, eval_mode: bool = False) -> None:
        self.trace_id = trace_id
        self.eval_mode = eval_mode
        self.spans: list[Span] = []

    def start(self, stage: str) -> Span:
        s = Span(stage=stage)
        self.spans.append(s)
        return s

    def to_payload(self) -> dict:
        return {
            "trace_id": self.trace_id,
            "eval_mode": self.eval_mode,
            "ts": time.time(),
            "spans": [s.to_dict() for s in self.spans],
        }

    def export_async(self) -> None:
        """旁路导出：任何异常吞掉只记日志，绝不阻塞主链（写侧纪律）。"""
        settings = get_settings()
        if settings.retrieval_trace_export == "file":
            payload = self.to_payload()
            asyncio.get_event_loop().run_in_executor(
                None, self._write_file, payload, Path(settings.retrieval_trace_dir)
            )
        # kafka/http 导出：后续按 EV-2 接入，此处预留分支

    @staticmethod
    def _write_file(payload: dict, dir_: Path) -> None:
        try:
            dir_.mkdir(parents=True, exist_ok=True)
            with (dir_ / f"{payload['trace_id']}.json").open("w", encoding="utf-8") as f:
                json.dump(payload, f, ensure_ascii=False, indent=2)
        except OSError:
            pass  # 旁路失败不影响主链
```

```python
    if _reranker is None:
        from FlagEmbedding import FlagReranker
        _reranker = FlagReranker(RERANK_MODEL, use_fp16=True)
    return _reranker

@app.post("/embed")
def embed(req: EmbedReq) -> dict:
    t0 = time.time()
    if EMBED_BACKEND == "bge_m3":
        m = _load_m3()
        out = m.encode(req.texts, return_dense=True, return_sparse=True) \
            if req.type == "doc" else \
            m.encode_queries(req.texts, return_dense=True, return_sparse=True)
        embs = [{"dense": out["dense_vecs"][i].tolist(),
                 "sparse": {str(k): float(v) for k, v in out["lexical_weights"][i].items()}}
                for i in range(len(req.texts))]
        dim = len(embs[0]["dense"])
    else:
        embs = [{"dense": hash_embedding(t), "sparse": hash_sparse(t)} for t in req.texts]
        dim = len(embs[0]["dense"]) if embs else 0
    return {"embeddings": embs, "dim": dim, "model": EMBED_MODEL,
            "backend": EMBED_BACKEND, "count": len(embs),
            "elapsed_ms": int((time.time() - t0) * 1000)}


@app.post("/rerank")
def rerank(req: RerankReq) -> dict:
    if RERANK_BACKEND == "bge":
        r = _load_reranker()
        scores = [float(x) for x in r.compute_score([[req.query, t] for t in req.texts])]
    else:
        from app.store.hash_embed import cosine
        qv = hash_embedding(req.query)
        scores = [round(max(0.0, (cosine(qv, hash_embedding(t)) + 1.0) / 2.0) ** 3, 6)
                  for t in req.texts]
    return {"scores": scores, "model": RERANK_MODEL, "backend": RERANK_BACKEND}


def _echo_answer(messages: list[dict]) -> str:
    """模板化"报告"：把证据条数与前若干条摘要组织成四要素。

    明确标注为 stub 产物，避免被误当真实模型输出（与"禁止编造"红线一致）。
    """
    user = next((m.get("content", "") for m in messages if m.get("role") == "user"), "")
    blocks: list[tuple[str, str]] = []
    cur = None
    for line in user.splitlines():
        if line.startswith("["):
            if cur:
                blocks.append(cur)
            cur = (line[1:line.find("]")], line[line.find("]") + 1:].strip())
        elif cur:
            cur = (cur[0], cur[1] + " " + line.strip())
    if cur:
        blocks.append(cur)
    q = user.split("用户问题：")[-1].split("\n")[0].strip() if "用户问题：" in user else ""

    lines = [f"【stub 生成 · 非真实模型输出】针对「{q}」的研判如下：", "", "一、相似信号列表"]
    for i, (_n, txt) in enumerate(blocks[:8], start=1):
        lines.append(f"[{i}] {txt[:70]}……")
    if not blocks:
        lines.append("（无命中证据，依据不足）")
    lines += [
        "",
        "二、关联路径：命中实体经图谱 1~2 跳关联，详见图谱页 focus 视图。",
        "三、规则触发详情：结构化条件按软语义参与排序，未做硬过滤（过渡期口径）。",
        "四、置信度：本段为 stub 模板输出，不代表模型判断；接入真实 LLM 后替换为证据支撑的结论。",
        "",
        "注：以上为流式链路演示文本，真实结论必须由 LLM 依据证据生成。",
    ]
    return "\n".join(lines)


def _sse_chunk(model: str, content: str) -> str:
    body = {"choices": [{"delta": {"content": content}, "index": 0, "finish_reason": None}],
            "model": model, "object": "chat.completion.chunk"}
    return f"data: {json.dumps(body, ensure_ascii=False)}\n\n"


@app.post("/v1/chat/completions")
def chat(req: ChatReq):
    if LLM_BACKEND == "vllm":
        import httpx
        r = httpx.post(LLM_UPSTREAM + "/chat/completions",
                       json=req.model_dump(), timeout=120.0)
        return r.json()

    text = _echo_answer(req.messages)
    model = f"stub-{LLM_BACKEND}"
    if not req.stream:
        return {"choices": [{"message": {"role": "assistant", "content": text},
                             "index": 0, "finish_reason": "stop"}],
                "model": model, "object": "chat.completion"}

    def gen():
        for i in range(0, len(text), 6):        # 每 6 字一个 chunk，模拟真实 token 流
            yield _sse_chunk(model, text[i:i + 6])
            time.sleep(0.01)
        yield _sse_chunk(model, "")
        yield "data: [DONE]\n\n"

    return StreamingResponse(gen(), media_type="text/event-stream")


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--port", type=int, default=8001)
    ap.add_argument("--host", default="127.0.0.1")

    uvicorn.run(app, host=args.host, port=args.port, log_level="info")
    return 0


if __name__ == "__main__":
```

```python
def load(name: str) -> list[dict]:
    p = SEED / f"{name}.json"
    if not p.exists():
        raise FileNotFoundError(f"seed 缺失 {p} —— 先跑 `python scripts/gen_seed.py`")
    return json.loads(p.read_text(encoding="utf-8"))


# ─────────────────────────── PG ───────────────────────────
async def seed_pg(dsn: str) -> int:
    import asyncpg

    parents, chunks = load("parents"), load("chunks")
    conn = await asyncpg.connect(dsn)
    try:
        await conn.executemany(
            """INSERT INTO parent_document
               (parent_id, doc_id, title, content, summary, keywords, content_version, kb_id, source_type, toa_text)
               VALUES ($1,$2,$3,$4,$5,$6::jsonb,$7,$8,$9,$10)
               ON CONFLICT (parent_id) DO UPDATE SET content=EXCLUDED.content,

def seed_neo4j(wipe: bool) -> int:
    from neo4j import GraphDatabase

    ents, edges, chunks = load("entities"), load("edges"), load("chunks")
    drv = GraphDatabase.driver(s.neo4j_uri, auth=(s.neo4j_user, s.neo4j_password))
    try:
        with drv.session() as sess:
            if wipe:
                sess.run("MATCH (n) DETACH DELETE n")
            sess.run(
                "UNWIND $rows AS r MERGE (e:Entity {entity_id: r.entity_id}) "
                "SET e.name = r.name, e.type = r.type, e.kb_id = r.kb_id",
                rows=[{"entity_id": e["entity_id"], "name": e["name"],
                       "type": e["type"], "kb_id": e.get("kb_id", "")} for e in ents])
            sess.run(
                "UNWIND $rows AS r MERGE (s:Segment {chunk_id: r.child_id}) "
                "SET s.parent_id = r.parent_id, s.content = r.content, s.kb_id = r.kb_id, "
                "    s.span_start = r.span_start, s.span_end = r.span_end",

                       "content": c["content"][:4000], "kb_id": c["kb_id"],
                       "span_start": int((c.get("span") or [0, 0])[0]),
                       "span_end": int((c.get("span") or [0, 0])[1])} for c in chunks])
            binds = [e for e in edges if e.get("rel") == "BINDS"]
            sess.run(
                "UNWIND $rows AS r MATCH (e:Entity {entity_id: r.src}) "
                "MATCH (s:Segment {chunk_id: r.dst}) MERGE (s)-[:BINDS]->(e)",
                rows=[{"src": e["src"], "dst": e["dst"]} for e in binds])
            typed = {}
            for e in edges:
                if e.get("rel") != "BINDS":
                    typed.setdefault(e["rel"], []).append(e)
            for rel, items in typed.items():
                sess.run(
                    f"UNWIND $rows AS r MATCH (a:Entity {{entity_id: r.src}}) "
                    f"MATCH (b:Entity {{entity_id: r.dst}}) "
                    f"MERGE (a)-[x:{rel}]->(b) "

                           "parent_id": (e.get("evidence") or {}).get("parent_id")}
                          for e in items])
        print(f"[seed_real] neo4j ok: entities={len(ents)} segments={len(chunks)} edges={len(edges)}")
```

```python
def parse_sse(lines) -> list[tuple[str, dict]]:
    out, ev, buf = [], None, []
    for raw in lines:

            raw = raw.decode("utf-8")
        if raw.startswith("event:"):

        elif raw.startswith("data:"):
```

```python
def _h(cid: str, score: float, src: str) -> Hit:

def test_rrf_one_source_one_vote():
    vec = [_h("a", 0.9, "vector_hybrid"), _h("b", 0.8, "vector_hybrid")]
```

```python
# C:/Users/djn24/OneDrive/桌面/retrieval/../qingxi/app/graphrag/embeddings.py
"""向量嵌入客户端(ems common/embeddings.py 移植,配置源改为 qingxi .env)。

provider:
  mock   字符 3-gram 哈希,确定性(同文本同向量,余弦 1.0)。
  openai text-embedding-3-large,走网络。
  bge    本地 FlagEmbedding(BAAI/bge-m3 或 bge-large-zh-v1.5,1024 维),懒加载缓存。
同步实现:mock 纯计算;openai/bge 由调用方经 asyncio.to_thread 委托。
"""

from __future__ import annotations

import hashlib
import logging
import math
import threading
from typing import Optional

from .config import build_settings


class EmbeddingClient:
    def __init__(self, settings: Optional[dict] = None):
        self.settings = settings or build_settings()
        self.provider = self.settings["embedding"]["provider"]
        self.dim = int(self.settings["embedding"]["dim"])

    def embed(self, texts: list[str]) -> list[list[float]]:
        if self.provider == "openai":
            return self._embed_openai(texts)
        if self.provider == "bge":
            return self._embed_bge(texts)
        return [_hash_embed(t, self.dim) for t in texts]

    def embed_one(self, text: str) -> list[float]:
        return self.embed([text])[0]

    def embed_m3_full(self, texts: list[str]) -> dict:
        """BGE-M3 全量输出接口（dense + sparse 同源产出）——text_sparse 列的写入通道。

        预留接口（2026-09-28 BGE-M3 全量定案）：当前入库链路仍只消费 dense；
        IF-1 重建 collection 带 text_sparse 列时，embed_and_upsert 改调本接口，
        把 sparse(lexical_weights) 一并落列，检索侧①路即可开 hybrid。
        返回：{"dense": [[float]], "sparse": [{token_id: weight}]}
        纪律：非 m3 模型调用即报错（sparse 无数据源，禁止静默降级为 dense-only 还当 hybrid 用）。
        """
        if self.provider != "bge" or "m3" not in self.settings["embedding"]["model"].lower():
            raise RuntimeError("embed_m3_full 仅 provider=bge 且模型为 BGE-M3 时可用")
        s = self.settings["embedding"]
        model = _load_bge(s["model"], s.get("device") or None, bool(s.get("use_fp16", False)))
        out = model.encode(texts, return_dense=True, return_sparse=True)
        return {
            "dense": _l2_normalize_rows(out["dense_vecs"]),
            "sparse": [dict(w) for w in out["lexical_weights"]],
        }

    def _embed_openai(self, texts: list[str]) -> list[list[float]]:
        from openai import OpenAI  # 延迟导入
        s = self.settings["embedding"]
        client = OpenAI(base_url=self.settings["llm"].get("base_url"),
                        api_key=self.settings["llm"].get("api_key") or "sk-dummy")
        resp = client.embeddings.create(model=s["model"], input=texts)
        return [d.embedding for d in resp.data]

    def _embed_bge(self, texts: list[str]) -> list[list[float]]:
        """BGE 本地向量(FlagEmbedding)。

        实体名两两比较是对称场景,不加 query/passage 指令,直接 dense 编码后 L2 归一化
        (与 mock 输出口径一致,配合 Milvus COSINE)。模型懒加载 + 进程级缓存,首次加载慢。
        """
        s = self.settings["embedding"]
        model_name = s["model"]
        model = _load_bge(model_name, s.get("device") or None, bool(s.get("use_fp16", False)))
        if "m3" in model_name.lower():
            dense = model.encode(texts)["dense_vecs"]
        else:
            dense = model.encode(texts)
        vecs = _l2_normalize_rows(dense)
        if vecs and len(vecs[0]) != self.dim:
            _bge_logger.warning("BGE 模型维度 %d 与配置 dim %d 不一致",
                                len(vecs[0]), self.dim)
        return vecs


def _hash_embed(text: str, dim: int) -> list[float]:
    """字符 3-gram 哈希嵌入:稳定、同文本同向量。"""
    vec = [0.0] * dim
    t = "  " + text + "  "
    for i in range(len(t) - 2):
        gram = t[i:i + 3]
        h = int(hashlib.md5(gram.encode("utf-8")).hexdigest(), 16)
        idx = h % dim
        sign = 1.0 if (h >> 8) % 2 == 0 else -1.0
        vec[idx] += sign
    norm = math.sqrt(sum(x * x for x in vec))
    if norm == 0:
        return vec
    return [x / norm for x in vec]


_bge_logger = logging.getLogger(__name__)
_bge_lock = threading.Lock()
_bge_models: dict[str, object] = {}


def _local_bge_path(model_name: str) -> str:
    """本地已缓存模型时返回其 snapshot 路径,否则回退原 repo id。

    FlagEmbedding 1.4.x 加载时会访问 hub 查 chat template(网络请求),离线环境会超时;
    本地缓存命中时直接给本地路径,彻底绕开网络。未缓存则回退 repo id 走在线下载。
    """
    try:
        from huggingface_hub import snapshot_download
        return snapshot_download(repo_id=model_name, local_files_only=True)
    except Exception:
        return model_name


def _load_bge(model_name: str, device, use_fp16: bool):
    """BGE 模型懒加载 + 进程级缓存(加载慢,不能每次 embed 都重建)。

    device/use_fp16 来自 .env;device 空串 -> devices=None(FlagEmbedding 自动选设备)。
    """
    with _bge_lock:
        if model_name in _bge_models:
            return _bge_models[model_name]
        model_path = _local_bge_path(model_name)
        from FlagEmbedding import BGEM3FlagModel, FlagModel  # 延迟导入
        devices = device or None
        if "m3" in model_name.lower():
            model = BGEM3FlagModel(model_path, devices=devices, use_fp16=use_fp16)
        else:
            model = FlagModel(model_path, devices=devices, use_fp16=use_fp16)
        _bge_models[model_name] = model
        return model


def _l2_normalize_rows(rows) -> list[list[float]]:
    out: list[list[float]] = []
    for r in rows:
        v = [float(x) for x in r]
        n = math.sqrt(sum(x * x for x in v))
        out.append([x / n for x in v] if n > 0 else v)
    return out


def get_embeddings() -> EmbeddingClient:
    return EmbeddingClient()
```
