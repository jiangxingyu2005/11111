# EQUIPPED_ON（装备于）few-shot 示例（方向：装备 → 平台/单位）

「平台 装备 X」「X 搭载于平台」都记为 (X, 平台, EQUIPPED_ON)。

正例（关系成立）：
1. "某舰艇装备一部对空搜索雷达。" → (对空搜索雷达, 某舰艇, EQUIPPED_ON)
2. "该型预警机搭载相控阵雷达。" → (相控阵雷达, 预警机, EQUIPPED_ON)
3. "ATACMS 导弹由 HIMARS 发射车发射。" → (ATACMS, HIMARS, EQUIPPED_ON)
4. "干扰吊舱挂载于战斗机翼下。" → (干扰吊舱, 战斗机, EQUIPPED_ON)

否定示例（非装备关系，不得抽成 EQUIPPED_ON）：
1. "该雷达下辖一部干扰机。" → 这是隶属，非装备
2. "在某舰艇附近采集到一段信号样本。" → 样本不是装备，用 平台候选/来源
