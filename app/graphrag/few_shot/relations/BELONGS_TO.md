# BELONGS_TO（隶属）few-shot 示例（条款(10)明文；方向：下级 → 上级）

「A 下辖 B」「B 配属 A」都记为 (B, A, BELONGS_TO)。

正例（关系成立）：
1. "该通信电台下辖两个跳频信号收发单元。" → (跳频信号收发单元, 电台, BELONGS_TO)
2. "该雷达隶属某防空旅的警戒雷达站。" → (雷达, 警戒雷达站, BELONGS_TO)
3. "干扰机配属某电子对抗营。" → (干扰机, 电子对抗营, BELONGS_TO)
4. "两架侦察机编成同一侦察分队。" → (侦察机, 侦察分队, BELONGS_TO)
5. "该雷达下辖一部干扰机。" → (干扰机, 雷达, BELONGS_TO)（辐射源之间允许）

否定示例（非隶属关系，不得抽成 BELONGS_TO）：
1. "该雷达为导弹部队提供目标指示。" → 这是支援，非隶属
2. "雷达与指挥所通过数据链交联。" → 这是交联，非隶属
3. "侦察设备将数据传输给指挥所。" → 这是交联，非隶属
4. "某舰艇装备一部雷达。" → 这是装备于，非隶属
