# BELONGS_TO（隶属）few-shot 示例

正例（关系成立）：
1. "该通信电台下辖两个跳频信号收发单元。" → (电台, 跳频信号收发单元, BELONGS_TO)
2. "该雷达隶属某防空旅的警戒雷达站。" → (雷达, 警戒雷达站, BELONGS_TO)
3. "干扰机配属某电子对抗营。" → (干扰机, 电子对抗营, BELONGS_TO)
4. "两架侦察机编成同一侦察分队。" → (侦察机, 侦察分队, BELONGS_TO)

否定示例（非隶属关系，不得抽成 BELONGS_TO）：
1. "该雷达为导弹部队提供目标指示。" → 这是支援，非隶属
2. "雷达与指挥所通过数据链交联。" → 这是交联，非隶属
